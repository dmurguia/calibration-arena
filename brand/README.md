## Approved direction — September 21, 2026

The art of better. The primary C is paper-white on charcoal (#464643). Leather brown (#70543E) is an accent only and must not color the logo or its backdrop. Archivo Black supplies the bold identity; IBM Plex Sans Regular handles headings, notes and reading, with IBM Plex Mono for code. Graphite sketching moves from loose human marks toward structured syntax.

The kit includes font files and licenses, SVG/PNG logos, image masters and web exports, color tokens, a motion prototype, and source tools. Earlier iterations are retained in [`archive/`](archive/) for reference; use the current kit for new work.

This folder documents the brand handoff. It does not deploy or restyle the application.
